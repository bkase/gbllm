## Caveats

- All timing is DMG M-cycle-accurate emulated time (gbf-emu headless), interrupts disabled, SP repurposed inside weight chunks; production kernels pay yield/safe-point overhead on top of these numbers.
- Token-boundary deltas include the VBlank-aligned transcript render, i.e. they are the real UI cadence a player sees, not bare forward-pass time.
- The first token boundary samples from the prompt-warmup logits (no forward pass), so its delta is structurally small; it is included in the percentile set and reported separately per row.
- The reference row (arm-B) is recorded for context only and is not asserted by this gate.
- The original bead title targeted <= 10 s/char at 70% CPU; the governing budget was revised to 30 s/char (bd-3771m comment 2026-07-04 15:15 UTC, quality-first). This gate asserts the revised budget against 100%-CPU sustained measurements (harder than the 70%-CPU formulation: no reserve is subtracted from the measured numbers).
